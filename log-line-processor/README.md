A log file line processor — a CLI tool that ingests raw log lines (as an array of strings, simulating lines read from a file — real fs reading comes in a later concept), extracts only ERROR-level entries, batches them into fixed-size chunks for processing (e.g., sending 5 at a time to some downstream system), and removes a known-bad line by exact match — a genuinely realistic backend/tooling scenario combining everything.

Main concept being drilled: Using splice in a loop to batch/chunk an array (a very common real-world pattern for processing large datasets in manageable pieces), combined with slice for non-destructive lookahead/preview, and indexOf/splice for targeted removal — all applied to realistically messy log data, indexOf + splice removal idiom, guard clauses, const/let discipline.
